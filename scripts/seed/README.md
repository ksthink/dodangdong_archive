# 가상 시험 자료

모든 기능을 시험하려고 넣은 **가상의** 인물·자료다. 실존 인물이나 실제 사건이 아니다
(바깥 세상 사건만 실제 한국 현대사다). 운영 DB 에 들어가 있어 사이트에서 그대로 보인다.

가짜 자료는 모두 제목이 ` (시험)` 으로 끝나는 가짜 묶음(DC-002 ~ DC-006)에 들어 있다.
실제 자료(DC-001 할머니의 전화번호부, 도당동 본가, 상위 주제 6개)는 건드리지 않는다.

## 들어 있는 것

| | 관리자 | 손님 | 시험하려는 것 |
| --- | --- | --- | --- |
| 자료 | 52 | 42 | EDTF 모든 형식, 확인된 날짜 8건, 비공개 10건 |
| 인물 | 12 | 11 | 비공개 자료에만 나오는 사람(DP-012) 은 손님에게 숨는다 |
| 이야기 | 3 | 2 | 블록 여섯 종류, 비공개 자료를 인용한 구술 블록은 통째로 숨는다 |
| 사진 | 9 | 8 | 실제 Drive 업로드 경로로 올렸다. 비공개 자료의 사진 1장은 손님에게 404 |
| 바깥 세상 | 12 | 12 | 같은 해 2건(1979)의 순서 |

1920·1950년대에는 비공개 자료만 있다 — 손님 연표에 그 연대 막대가 생기지 않아야 한다.

## 스크립트

```bash
ADMIN_PASSWORD='…' python3 scripts/seed/fake_seed.py     # 인물·장소·주제·묶음·자료·사진·이야기
ADMIN_PASSWORD='…' python3 scripts/seed/fake_world.py    # 바깥 세상 12건
ADMIN_PASSWORD='…' python3 scripts/seed/fake_cleanup.py  # 지울 것을 보여 주기만 한다(드라이런)
ADMIN_PASSWORD='…' python3 scripts/seed/fake_cleanup.py --execute  # 실제로 지운다
```

- `ADMIN_PASSWORD` 는 관리자 비밀번호다. 어떤 파일에도 쓰지 않는다.
- 사진을 올리려면 `fake_seed.py` 를 돌리는 동안 로컬 서버(`npm run start -- -p 3200`)가 떠 있어야 한다
  — 앱의 실제 업로드 경로(`/api/drive/session` → PUT → `/api/drive/register`)를 탄다.
- 두 번 돌려도 두 벌이 되지 않는다. 이미 넣었으면 멈춘다.

## 무엇을 넣었는지는 DB 가 기억한다

`app_setting` 의 `seed_fake_manifest`(자료·인물·묶음·사진·이야기)와 `seed_fake_manifest:*`
(`:world` 바깥 세상, `:stories` 이야기 — 같은 id 가 겹쳐도 된다)에 만든 행의 id 가 있다.
정리 스크립트는 이것들을 합쳐 읽고, **여기 적힌 것만** 지운다.

## 정리 스크립트의 안전장치

- 지우기 전에 각 id 가 실제로 있는지 확인한다.
- 가짜 묶음이 아닌 묶음의 자료가 목록에 섞여 있으면 아무것도 지우지 않고 멈춘다.
- DC-001, 도당동 본가, 상위 주제, 바깥 루트 Drive 폴더("도당동 아카이브")는 목록에 있어도 지우지 않는다.
- 순서: Drive 파일 → Drive 폴더(가짜 묶음 것만) → event_log(가짜 자료를 고친 기록 — 자료를
  지우면 연결이 풀려 누구 것인지 모르게 되므로 먼저) → 이야기 → 자료 → 묶음 → 인물 →
  장소·하위 주제·바깥 세상 → 목록 행.
- 끝나면 표마다 남은 건수와, 표가 비었을 때 돌릴 채번 되돌리기 SQL 을 보여 준다(직접 돌리지는 않는다).
